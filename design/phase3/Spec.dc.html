Phase 3 · query workspace
The numbers an implementer needs, and the one rule the whole thing rests on.
Every neutral surface reads a VS Code theme token, so the workspace follows the user's theme with no detection of its own. The values below are the literals — the object hues, the environment hues and the plan ramp — and each was measured against the ground it sits on.
The rule
The host owns state. A webview is a projection with a scroll position.
Three things live in a webview and only three: scroll offset, column widths, selection rectangle. All three survive a disposal through vscode.setState. Everything else changes what the host has to fetch, so the host holds it.

Rows on the wire
type RowMessage = {
  executionId: string;
  offset: number;
  rows: CellValue[][];
};
Arrays, never objects. Column names travel once. Thirty-four string keys per row across a million rows is thirty-four million strings carrying no information after the first one.
bigint, Buffer and Date do not survive structured cloning intact, so each is tagged { t, v }. A datetime2 rendered through the browser's locale is the most common data-corruption bug in this category of tool.
